Adaptive Context Compression for Long-Context Reasoning in LLM Agents

Gangshin Lee, Minji Park, Sanghoon Lee, Wonhyung Park

Annual Meeting of the Association for Computational Linguistics (ACL 2025)

Abstract: Large Language Models (LLMs) often suffer from severe memory footprint and latency degradation when reasoning over extended contexts (>64k tokens). In this paper, we propose AdaContext, an entropy-guided attention cache compression method that selectively preserves crucial reasoning traces while discarding redundant intermediate tokens. Comprehensive experiments across 8 benchmark suites demonstrate a 2.4x speedup and 46% memory reduction with virtually zero loss in reasoning fidelity.

Multimodal Representation Learning with Dynamic Cross-Attention Mechanisms

Gangshin Lee, Jinwoo Choi, Sung-Eun Kim

IEEE Transactions on Pattern Analysis and Machine Intelligence (TPAMI), Vol. 46, No. 8, pp. 5210-5226

Abstract: Aligning heterogeneous visual and linguistic representations requires flexible cross-modal grounding. We introduce DynCross, an adaptive sparse attention framework that calculates semantic affinity across modalities on the fly. The proposed framework significantly outperforms prior cross-attention baselines on VQA v2, MS-COCO Retrieval, and RefCOCO while lowering FLOPs by 34%.

Efficient Fine-Tuning for Edge Devices via Sparse Low-Rank Adaptation

Sanghoon Lee*, Gangshin Lee* (*Co-first authors), Junho Ha, Wonhyung Park

Advances in Neural Information Processing Systems 36 (NeurIPS 2023)

Abstract: Parameter-efficient fine-tuning (PEFT) has democratized adaptation of massive foundation models. However, backpropagation on edge hardware remains constrained by peak SRAM limits. We formulate SpLoRA, introducing structured sparse low-rank factors that decouple gradient tracking across layers, achieving a 58% reduction in activation memory without sacrificing downstream task accuracy.
